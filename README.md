# Market Lens — FunPay Analyzer

Веб-приложение для анализа публичных предложений FunPay. Основной раздел — **Dota 2 → аккаунты**: цены, продавцы, конкуренция и изменение объявлений во времени.

**Статус:** рабочий локальный прототип. Последние доработки реализованы и проверены в рабочей копии. Этот коммит публикует только README; код последних доработок пока не отправлен на GitHub.

## Реализовано

| Раздел | Возможности |
| --- | --- |
| Обзор рынка | Медиана, средняя цена, минимум/максимум, квартили, количество предложений и продавцов; сравнение с предыдущим периодом |
| Графики | Динамика цен и количества лотов, распределение цен, история отдельного объявления |
| Фильтры | Категория, период, цена, отзывы, онлайн-статус в снимке, поиск по описанию или продавцу |
| Предложения | Сортировка, пагинация, карточка лота, избранное на текущей странице, экспорт CSV |
| Сбор данных | Ручной запуск, расписание, журнал результатов и ошибок, настройка срока хранения |
| Работа с категориями | Готовые разделы Dota 2 и добавление публичного раздела по ссылке FunPay |

### Доработки последнего этапа

- **Аккаунты:** продажа и аренда анализируются отдельно; по умолчанию выбрана продажа. Добавлены диапазон MMR и два дополнительных параметра одновременно.
- **Продавцы:** полный список вместо топ-12, поиск, сортировка, пагинация, диапазон цен и переход к предложениям конкретного продавца.
- **Конкуренция:** доли всех продавцов по числу объявлений, доля трёх лидеров, число лотов на продавца и индекс концентрации HHI.
- **Ценовые сегменты:** нижний, основной и верхний сегменты по квартилям; переход к лотам основного сегмента.
- **Движение рынка:** появившиеся и исчезнувшие из выборки объявления, повышение и снижение цен одних и тех же лотов.
- **Гистограмма:** переключение линейных и логарифмических интервалов для анализа цен с большим разбросом.
- **Интерфейс:** адаптивная компоновка, читаемые подписи, видимые активные фильтры и их сброс.
- **Запуск:** подготовлены `start-local.sh` для macOS/Linux и `start-local.command` для macOS; добавлен npm lockfile.

## Запуск

Рекомендуется **Node.js 24 LTS**.

```sh
npm install
npm run build
npm start
```

Открыть [http://127.0.0.1:3400](http://127.0.0.1:3400).

1. Нажать **«Собрать сейчас»** для получения реального снимка.
2. Выбрать **«Реальные данные»** и нужные категорию, период и фильтры.
3. В разделе **«Сбор данных»** включить расписание и сохранить настройки для накопления истории.

Пока реальных снимков нет, доступен явно обозначенный демо-режим с синтетической историей за 30 дней. Демо хранится отдельно в памяти и не записывается в рабочую SQLite-базу. Для сбора по расписанию сервер должен продолжать работать.

Разработка: `npm run dev` запускает API на порту 3400, `npm run dev:ui` — Vite на порту 5173. Проверки: `npm test` и `npm run build`.

### Docker

```sh
cp .env.example .env
# Указать собственный ANALYZER_PASSWORD в .env
docker compose up -d --build
```

База сохраняется в томе `market-data`. Контейнер перезапускается автоматически. Запускать одну реплику: планировщик работает внутри серверного процесса. Порт по умолчанию доступен только через localhost; для удалённого доступа использовать SSH-туннель или HTTPS reverse proxy.

| Переменная | Назначение / значение по умолчанию |
| --- | --- |
| `PORT` | Порт сервера: `3400` |
| `HOST` | Адрес прослушивания: `127.0.0.1` |
| `DATABASE_PATH` | База: `data/market.sqlite` |
| `ANALYZER_USER` | Логин: `admin` |
| `ANALYZER_PASSWORD` | Пароль HTTP Basic; обязателен в production |

При обычном `npm start` файл `.env` автоматически не читается. Для загрузки использовать `node --env-file=.env server/index.mjs`; Docker Compose передаёт переменные из `.env` самостоятельно. HTTP Basic использовать через HTTPS или SSH-туннель.

## Как считаются показатели

- **Сводка, продавцы и CSV:** последний снимок каждой выбранной категории внутри периода. Повторные наблюдения одного лота не складываются как разные предложения.
- **График:** последний снимок каждого дня по каждой категории. Даты и границы суток — Москва, UTC+3. Дни без данных остаются пустыми.
- **Движение:** первый и последний снимки периода отдельно по категориям. Нужны минимум два снимка. Фильтры применяются к обоим; промежуточные изменения не суммируются.
- **HHI:** сумма квадратов процентных долей всех продавцов по количеству лотов; шкала 0–10 000. Чем выше значение, тем сильнее сосредоточено предложение в выборке.
- **Ценовые сегменты:** ниже P25; от P25 до P75 включительно; выше P75. При одинаковых ценах доли сегментов могут отличаться от 25/50/25%.
- **MMR:** числовое поле `solommr`. При активном диапазоне объявления без числового MMR исключаются. Дополнительные параметры берутся из `data-f-*`; список значений ограничен 60 на ключ.

## Ограничения

**Подтверждённые продажи, выручка и конверсия недоступны в публичном каталоге.** Исчезновение объявления не считается продажей: его могли удалить, скрыть или исключить из выдачи. Изменение цены либо параметров также может вывести лот за границы фильтра.

История начинается с запуска сборщика; данные за прошлые месяцы автоматически не восстанавливаются. FunPay может отдавать неполную выборку. Покрытие отображается по исходному снимку и не меняется при фильтрации; показатели не экстраполируются на весь рынок. Сравнение цен разных категорий может смешивать разные товары и единицы услуг.

Сборщик читает публичные объявления в рублях, без авторизации и обхода защиты. При CAPTCHA, ошибке HTTP, другой валюте или пустом разборе новый снимок не создаётся; сохраняется последний успешный результат. Между категориями пауза 5 секунд, таймаут запроса 45 секунд, лимит ответа 20 МБ, минимальный интервал сбора 15 минут.

Отзывы относятся ко всему профилю продавца. Онлайн-статус фиксируется при сборе. Избранное и сохранённые виды находятся в localStorage браузера.

## Хранение и структура

SQLite использует WAL и атомарное сохранение снимков. Данные старше установленного срока удаляются после сбора. Объём базы растёт с числом категорий, лотов и частотой снимков. Для резервной копии остановить сервер и сохранить весь каталог базы или Docker-том, включая WAL-файлы. Удаление тома уничтожает историю.

```text
src/                  React-интерфейс, графики и стили
server/db.mjs         SQLite, снимки, настройки и демо
server/collector.mjs  Парсер публичных страниц и планировщик
server/analytics.mjs  Фильтры, статистика, графики и CSV
server/market.mjs     Конкуренция и движение предложений (локальная доработка)
server/index.mjs      HTTP API, доступ по паролю и раздача интерфейса
tests/                Автоматические проверки
```

Стек: React 19, TypeScript, Recharts, Lucide, Vite, Node.js, Express, SQLite, Cheerio и Zod.
