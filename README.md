# Market Lens · FunPay Analyzer

Личный анализатор рынка Dota 2: React + TypeScript + Recharts, Node.js + Express, SQLite. Русский интерфейс, постоянный серверный сбор и прозрачная статистика публичных объявлений.

## Возможности

- Категории Dota 2: аккаунты, буст MMR, калибровка, предметы, отмыв ЛП, обучение, Dota+ и VHS. Можно добавлять разделы по ссылке.
- Период, цена, онлайн-статус на момент снимка, минимальное число отзывов, поиск по описанию/продавцу и параметры из `data-f-*` (например, MMR).
- Медиана, средняя, квартильный диапазон, число объявлений и уникальных продавцов; сравнение с предыдущим периодом той же длины.
- График цены/числа лотов, гистограмма, сравнение категорий, топ продавцов, история отдельного объявления.
- Пагинация, сортировка, избранное на текущей странице, сохранённые фильтры в браузере, CSV текущей выборки.
- Сбор по расписанию, журнал ошибок, срок хранения, отдельная демонстрационная база в памяти.

## Локальный запуск

Нужен **Node.js 22.13+**, рекомендуется **Node.js 24 LTS**, и pnpm 11.25.0. Старый Node.js 16 не поддерживается (`node:sqlite` отсутствует).

```sh
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Открыть http://127.0.0.1:3400. Если реальных снимков ещё нет, интерфейс открывает явно обозначенную демо-выборку. Нажмите «Собрать сейчас», затем переключитесь на «Реальные данные». Для постоянного сбора откройте «Сбор данных», включите расписание и сохраните настройки. По умолчанию активны аккаунты, буст и калибровка; расписание выключено до настройки.

На Windows после установки и сборки можно запустить `start-local.cmd`. Он использует Node.js из Codex runtime, если тот установлен, иначе системный Node.js, и проверяет версию. Закрытие окна останавливает сервер. Этот файл удобен для просмотра; постоянный сервер запускайте через Docker.

Разработка: `pnpm dev` (API :3400) и отдельно `pnpm dev:ui` (Vite :5173). Проверки: `pnpm test` и `pnpm build`.

## Сервер / Docker

```sh
cp .env.example .env
# Заменить ANALYZER_PASSWORD в .env на свой пароль
docker compose up -d --build
```

Контейнер автоматически перезапускается и сохраняет базу в томе `market-data`. По умолчанию порт привязан к localhost сервера. Открывайте через SSH-туннель или HTTPS reverse proxy (Caddy / nginx). Для SSH-туннеля: `ssh -L 3400:127.0.0.1:3400 user@server`. Логин по умолчанию `admin`, пароль из `.env`. HTTP Basic должен использоваться через HTTPS или SSH-туннель.

Запускайте **одну реплику**: планировщик находится внутри процесса. После перезапуска сохранённое расписание возобновляется, ближайший сбор — через настроенный интервал. Состояние доступно в интерфейсе. Постоянный сбор работает только при работающем сервере.

Переменные окружения: `PORT` (3400), `HOST` (127.0.0.1), `DATABASE_PATH` (`data/market.sqlite`), `ANALYZER_USER` (`admin`), `ANALYZER_PASSWORD`. Production требует пароль. При обычном `node server/index.mjs` `.env` автоматически не загружается; используйте `node --env-file=.env server/index.mjs` или переменные среды. Docker Compose читает `.env` самостоятельно.

## Что именно измеряется

1. **Это предложения, а не продажи.** Публичный каталог не подтверждает факты сделок, выручку или конверсию. Исчезновение лота не считается продажей.
2. История начинается с запуска сборщика. Данные за прошлые месяцы автоматически не восстанавливаются. Демо-история синтетическая, хранится отдельно в памяти и никогда не попадает в настоящую SQLite-базу.
3. Карточки, таблица, распределение, продавцы и CSV используют **последний снимок каждой категории внутри выбранного периода**. Исторические наблюдения одного лота не суммируются как разные предложения. График берёт последний снимок каждого дня по каждой категории; все фильтры применяются и к графику.
4. Даты и суточные границы — Москва, UTC+3. Дни без наблюдений не заполняются выдуманными значениями. При нескольких категориях график показывает отдельную линию каждой; общая медиана может смешивать разные товары/единицы услуги, поэтому для ценового анализа лучше выбирать один раздел и однородный параметр лота.
5. Один HTTP-запрос на категорию, без обхода защиты или авторизации. В проверенной странице FunPay возвращалось **3000 лотов из 5446**. Это ограниченная выборка, а не весь рынок. Покрытие вычисляется по счётчику категории; если счётчик отсутствует, оно неизвестно. Отфильтрованные показатели не меняют показатель покрытия исходного снимка. Изменение состава выборки способно менять медиану без изменения цен конкретных лотов.
6. При ошибке, CAPTCHA, другой валюте или пустом разборе новый снимок не создаётся. Последний успешный снимок остаётся доступным с датой; журнал показывает ошибку. Между категориями пауза 5 секунд, сетевой таймаут 45 секунд, лимит ответа 20 МБ, минимальный интервал 15 минут. При HTTP 403/429 сборщик ждёт следующего планового запуска. Лишь публичные объявления в рублях.
7. Число отзывов — по профилю продавца, не только по Dota 2. Онлайн-статус зафиксирован в момент сбора, не проверяется непрерывно.
8. Сохранённые виды и избранное находятся в localStorage текущего браузера; это не многопользовательский сервис. CSV выгружает последние снимки с текущими фильтрами, а не полный архив всех наблюдений.

## Хранение и обслуживание

Снимок и его лоты сохраняются одной транзакцией; WAL и внешние ключи включены. История старше срока хранения удаляется после прохода сборщика. Сбор по 3 категориям × 3000 лотов каждый час за 30 дней — до **6,5 млн строк**; дисковый объём зависит от длины описаний. Следите за свободным местом, увеличивайте интервал или сокращайте срок хранения. После удаления SQLite переиспользует освободившееся место; физический файл не обязан уменьшаться. Для сжатия остановите приложение и выполните SQLite `VACUUM` с достаточным запасом места.

Для резервной копии остановите контейнер и сохраните **весь том** `market-data` (включая WAL-файлы, если они есть), затем запустите снова. Не удаляйте том командой `docker compose down -v`, если история нужна.

Разметка FunPay может измениться. Парсер изолирован в `server/collector.mjs`; контрольная HTML-разметка без персональных данных проверяется тестами. При изменении разметки сверяйте значения и обновляйте парсер.

## Структура

```text
src/                  React-интерфейс и стили
server/db.mjs         SQLite, схема, атомарное сохранение, демо
server/collector.mjs  Сбор публичных страниц и планировщик
server/analytics.mjs  Фильтры, статистика, графики и CSV
server/index.mjs      API, доступ по паролю и сервер интерфейса
tests/                Расчёты, границы дат, парсер, API и доступ
```

Неофициальный независимый проект. Источник объявлений — [каталог Dota 2 на FunPay](https://funpay.com/lots/81/).
